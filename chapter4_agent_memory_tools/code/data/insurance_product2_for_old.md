## 一、 产品概述与核心要素

### 1. 设立初衷

成年人作为家庭的经济支柱，面临着高强度的工作压力与生活压力，一旦遭遇重大疾病或严重意外，不仅面临高昂的医疗费用，更伴随着收入中断的危机。“中坚力量综合健康保障计划”旨在为成年人提供全方位、高保额的健康防御盾牌，延续对家庭的责任与爱。

## 二、 保障责任与等待期详解

本计划针对成人的核心风险进行了模块化设计，提供深度的健康捍卫。

### 1. 重大疾病与特定疾病责任

* **保障内容：** 确诊合同约定的重大疾病（如恶性肿瘤、急性心肌梗死等）、中症或轻症，一经保司核定即按约定保额给付保险金，用于弥补收入损失与后续康复费。
* **等待期规则：** * 本产品疾病责任设有 **90 天** 的等待期。
* **重要提示：** 等待期内因非意外原因确诊合同约定的疾病或出现相关症状，保险公司不承担保险责任并可能终止合同或退还保费，具体严格以合同条款为准。



### 2. 百万大额医疗责任

* **保障内容：** 针对住院发生的合理且必要的医疗费用，在扣除免赔额后按约定比例（最高达 100%）进行报销，突破医保限制，涵盖自费药与质子重离子治疗。
* **等待期规则：** 同为 **90 天**（意外导致的住院除外）。

### 3. 综合意外保障责任

* **保障内容：** 涵盖交通意外、工作及日常生活意外导致的身故或伤残责任。
* **生效时间：** 意外责任无等待期，**自合同生效且保费划扣成功之日起承担**，具体以保单约定为准。

## 三、 灵活的缴费与退保机制

### 1. 缴费方式与维持

投保人可在投保时锁定年缴或月缴。采用月缴方式的投保人，应确保每月约定划款账户资金充足。若发生扣款失败，产品通常提供一定的宽限期（如 60 天），宽限期内保单继续有效，逾期未补缴则保单效力中止。

### 2. 退保权益与风险提示

* **犹豫期内退保：** * 自收到电子保单或签收回执之日起享有 **15 天犹豫期**。
* 在犹豫期内申请撤单退保，保险公司将全额退还已交保费，对您的资金无损失。


* **犹豫期后退保：**
* 犹豫期后投保人由于自身原因要求解除合同的，保险公司将退还**合同终止当日的现金价值**。
* **风险警告：** 成人长期或定期健康险在保单前几年，其现金价值往往远低于已交保费。犹豫期后退保将**蒙受较大的资金损失**。此外，随着年龄增长或健康状况变化，退保后可能因“超龄”或“健康告知不通过”而**无法再次购买任何商业保险**，请务必审慎对待。

## 四、 规范化理赔指南

为确保成人在面临出险时能够实现高效理赔，请悉知以下操作流程及材料规范：

### 1. 常见理赔申请材料清单

* **身份证明：** 被保险人及理赔申请人的有效身份证件。
* **重疾给付类材料：** 专科医生出具的诊断证明书、相关的病理切片报告、血液检查报告、影像学报告（MRI/CT）及其他具备法律效力的医学确诊凭证。
* **医疗报销类材料：** 原始医疗费用收据、住院费用总清单、出院小结/出院志、门急诊病历。
* **意外伤残类材料：** 具备资质的鉴定机构出具的伤残程度鉴定书、交通事故责任认定书（如涉及车祸）。

### 2. 理赔时效与流程

发生保险事故后，请于 10 日内通过客服电话、官方 APP 或微信公众号进行报案。保险公司在收到完整的理赔材料后，将依法依约进行审核，具体理赔时效和结案通知以保险公司公布的标准化服务承诺为准。

## 五、 核心注意事项（投保前必读）

* **非最终承诺：** 本资料仅作为产品的要约邀请与利益演示，**不构成具体的费率承诺、收益保证和最终理赔结论**。
* **如实告知义务：** 成人投保时必须**严格遵循“如实告知”原则**。在填写健康告知时，请务必就已知健康状况、过往就医史如实回答。若有隐瞒，可能导致合同解除或理赔时被依法拒赔。
* **最终以合同为准：** 任何个体的核保结论（是否加费、除外、拒保）及具体的赔付限额，**均以正式签发的保险合同文本及保险公司人工核实结果为准**。
