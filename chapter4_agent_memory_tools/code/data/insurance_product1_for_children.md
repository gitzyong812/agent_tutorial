# 【少儿专属】示例健康保障计划产品介绍资料

## 一、 产品概述与核心要素

### 1. 设立初衷

儿童成长阶段身体免疫系统尚未发育完全，且缺乏自我保护意识，面临着较高的疾病与意外风险。“示例健康保障计划”专为少儿女性量身定制，旨在通过科学的保额搭建与人性化的责任设计，为孩子的成长之路筑起一道坚实的医疗安全网。

### 2. 核心要素表

| 投保要素 | 详细规则与说明 |
| --- | --- |
| **产品名称** | 示例健康保障计划 |
| **适用人群** | **女性 0 至 10 周岁**（具体以投保时系统的投保规则校验为准） |
| **保障期限** | 1 年（期满可申请续保，具体续保规则见合同条款） |
| **保障范围** | 覆盖合同约定的**疾病医疗责任**与**意外医疗责任** |
| **缴费周期** | 支持**年缴**、**月缴**两种方式，投保人可根据财务规划自由选择 |

---

## 二、 保障责任与等待期详解

本计划采取“疾病+意外”双轮驱动的保障模式，全方位分担育儿过程中的医疗费用支出。

### 1. 疾病医疗保障

* **保障内容：** 尊享合同约定的疾病住院、指定门急诊发生的合理且必要的医疗费用报销。
* **等待期（观察期）规则：**
* 本产品疾病责任设有 **90 天** 的等待期。
* **重要提示：** 自合同生效之日起 90 天内（含第 90 天）为等待期。等待期内因疾病导致的医疗费用或相关申请，保险公司不承担给付保险金的责任，具体处理方案应严格以合同条款为准。设置等待期旨在防范逆选择与恶意投保，保障全体投保会员的公平权益。



### 2. 意外医疗保障

* **保障内容：** 覆盖儿童常见的跌倒跑跳、猫抓狗咬、烧伤烫伤等意外伤害导致的医疗费用。
* **生效时间：** 意外责任无等待期，通常**自合同生效起即开始承担**责任，具体以保单载明的生效时间及条款约定为准。

## 三、 灵活的缴费与退保机制

### 1. 缴费方式变更

投保人在投保时可勾选“年缴”或“月缴”。后续在保单有效期内如需变更缴费周期（如由月缴变更为年缴），需向保险公司提出书面申请，后续变更的具体准入条件及流程以保险公司届时公布的规则为准。

### 2. 退保权益与风险提示

* **犹豫期内退保：** * 自投保人签收保单/电子保单生效之日起享有一定天数的犹豫期（通常为 10-15 天，具体天数详见正式合同）。
* 在犹豫期内，若投保人认为本产品不符合预期，申请退保通常可**全额退还已交保费**（部分渠道可能会扣除工本费）。


* **犹豫期后退保：**
* 犹豫期后投保人申请解除合同的，保险公司自收到解除合同申请书之日起合同终止。
* 保险公司将按合同约定退还**保单的现金价值**（或未满期净保费）。
* **风险警告：** 犹豫期后退保，现金价值通常明显低于已交保费，**可能会产生较大的经济损失**。同时，退保后孩子将失去保障，再次投保需重新计算等待期并核保，请务必谨慎决定。

## 四、 规范化理赔指南

当不幸发生、需要申请理赔时，请按照以下指南准备材料，以便保险公司快速为您审核：

### 1. 常见理赔申请材料清单

* **身份证明：** 申请人（监护人）有效身份证件、出险儿童的户口本或身份证。
* **保单信息：** 电子保单号或纸质保单复印件。
* **医疗票据：** 医院出具的医疗费用收据原件（或符合合规要求的电子发票）、费用明细清单。
* **诊断证明：** 门诊病历、住院病案首页、出院小结、相关医学检查报告单（如 X 光、CT、化验单等）。
* **其他材料：** 银行账户信息（用于接收理赔款）以及保险公司根据具体案情要求的其他材料。

### 2. 理赔时效与流程

具体的理赔报案时效（如出险后 10 日内报案）、审核时效以及详细的线上/线下理赔流程，请以保险公司官方渠道公布的最新规则为准。

## 五、 核心注意事项（投保前必读）

* **非费率与收益承诺：** 本文档仅作为产品要约邀请和宣传介绍资料，**不包含具体费率表、任何收益承诺和最终的理赔结论**。
* **人工核保为准：** 涉及个体的最终核保结果（如因过往病史导致加费、除外责任、延期或拒保）以及最终的赔付金额，**必须以正式生成的保险合同文本和保险公司人工核实、审批结论为准**。
