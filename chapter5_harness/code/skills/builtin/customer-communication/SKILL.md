# 保险客户沟通话术

## 适用场景

用于保险咨询、续期提醒、理赔进度说明和服务回访等日常客户沟通。不得把示例话术表述为正式承保、理赔或收益承诺。

## 必要输入

- 沟通对象及其已知背景
- 本次沟通目标
- 已确认的业务事实
- 沟通渠道，如电话、短信或在线消息

信息不足时，先询问沟通目标和关键事实，不猜测客户情况。

## 执行步骤

1. 识别客户当前最关心的问题和可能的情绪。
2. 用一句话说明联系目的，避免冗长铺垫。
3. 先回应客户关切，再说明已确认的事实和下一步安排。
4. 对不确定事项明确说明需要核实，不作未经授权的承诺。
5. 根据沟通渠道调整长度和语气，最后给出清晰的后续动作。

## 输出要求

输出“沟通目标、推荐话术、注意事项”三部分。话术使用自然口语，尊重客户，不施加压力，不夸大保障范围或收益。

## 停止条件

涉及投诉升级、重大理赔争议、客户明确拒绝继续沟通，或需要作出业务决定时，停止生成推进性话术并建议转人工处理。
