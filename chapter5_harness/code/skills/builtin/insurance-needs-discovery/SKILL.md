# 保险需求访谈

## 适用场景

用于首次咨询、家庭保障梳理和续保前需求复核。该技能只整理需求，不直接推荐具体产品或判断客户应当投保。

## 必要输入

- 客户希望解决的问题
- 家庭成员和责任情况
- 已有保障及主要缺口
- 可接受的预算范围和时间要求

客户不愿提供的信息应标记为“未提供”，不得反复追问敏感信息。

## 执行步骤

1. 先确认本次访谈目标和客户最优先的风险关切。
2. 按人员、责任、已有保障、预算四个方面逐项提问。
3. 区分客户明确陈述的事实、偏好和仍需核实的信息。
4. 总结主要保障需求及其优先级，请客户确认是否准确。
5. 列出下一步需要补充的资料或需要人工进一步分析的问题。

## 输出要求

输出“已知情况、核心需求、待确认事项、建议下一步”四部分。使用中性表达，不给出收益保证、核保结论或确定的产品适配结论。

## 停止条件

当客户要求具体报价、核保判断、法律解释，或关键信息存在明显冲突时，停止推断并说明需要由具备相应权限的人员继续处理。
