# 从对话创建技能

## 执行步骤

1. 根据用户的创建要求，从提供的会话记录中识别可复用的任务场景和成功做法。
2. 区分稳定流程与本次对话中的偶然信息，不写入客户身份、账号、密钥或其他敏感数据。
3. 生成一个简洁的 `SKILL.md`，frontmatter 包含 `name`、`description` 和 `version`。
4. 正文写清必要输入、执行步骤、输出要求和停止条件，不声明或授予工具权限。
5. 调用内部 `create_skill` 能力保存完整文档。若名称冲突，改用更具体的名称后重试，不覆盖已有技能。

## 输出要求

- 名称使用小写字母、数字和连字符，长度不超过 64 个字符。
- 描述同时说明技能做什么以及什么情况下使用。
- 只创建 `SKILL.md`，不生成脚本、参考资料或资源文件。
- 创建成功后返回技能名称，并说明需要在技能管理页手动绑定到数字员工。

## 停止条件

会话中没有足够的完整问答、用户要求不明确，或无法在不包含敏感信息的情况下形成稳定流程时，不创建技能，并说明还需要哪些信息。
