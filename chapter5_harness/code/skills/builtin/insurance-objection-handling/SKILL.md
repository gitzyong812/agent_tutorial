# 保险异议处理

## 适用场景

用于回应客户对价格、保障范围、理赔条件、必要性和服务体验的疑问。目标是澄清信息和帮助决策，不是强行说服客户。

## 必要输入

- 客户的原始异议
- 已确认的产品或服务事实
- 当前沟通阶段
- 客户已经表达的偏好和限制

缺少事实依据时，只能提出核实建议，不能自行补充条款或结论。

## 执行步骤

1. 用简短语句复述客户顾虑，确认理解是否准确。
2. 判断顾虑属于信息不清、成本压力、信任问题还是需求不匹配。
3. 先认可顾虑的合理性，再基于已确认事实作出回应。
4. 提供一个便于客户选择的下一步，如补充资料、比较方案或转人工解释。
5. 检查回应中是否包含夸大宣传、绝对承诺或对客户施压的表达。

## 输出要求

输出“异议判断、建议回应、可选下一步、合规提醒”四部分。回应保持简洁，不贬低其他产品，不回避限制条件。

## 停止条件

客户明确拒绝、提出投诉、质疑销售误导，或问题涉及正式条款解释和争议处理时，停止劝说并建议转人工服务。
